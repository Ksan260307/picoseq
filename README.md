# PicoSeq — レトロピコピコ・シーケンサー

ファミコン風のピコピコ音楽を作って鳴らすデスクトップアプリ。
マス目に音を置くだけで演奏でき、写真からも曲を作れます。

**English version: [README.en.md](README.en.md)**

## 特長

- マス目に音を置いてフレーズを作り、フレーズを並べて 1 曲に組み立てる
- 4 パート（メロディ / ベース / リズム / サブ）を重ねられる
- **🧅 パートごとのレイヤー** — 各パートは「＋ 追加」で最大 8 層まで重ねられる。
  層ごとに音色・音を分けてハモリや厚みを作れ、✨ 自動作成は各層にも音を入れる（最大 32 声）。
  重ねる層は**下の層と同じ音を同じ位置で鳴らさない** — 重なると音量が上がるだけで
  層を足した意味が無いため、リズムは 16 分ずらして裏で鳴らし（ゴーストノート）、
  音程のあるパートはオクターブへ逃がす（ユニゾン → オクターブ重ね）
- **🔇 ミュート（パート・レイヤー別）** — パート単位でも、パート内のレイヤー単位でも消音を切り替え。
  再生・WAV 書き出しに反映（確定状態は変えない）
- **🔍 盤面の拡大・縮小** — ピアノロールを拡大／縮小（ヘッダーの － / ＋、または Ctrl＋ホイール）。
  セルの幅・高さが一緒に変わり、拡大時は横スクロールできる
- **🪟 可変・切り離し可能なレイアウト** — 各パネル（操作・ピアノロール・ソング）は
  境界線のドラッグで大きさを変えられ、「⧉ 切り離し」で独立ウィンドウにもできる
- **🌐 日本語 / English 切替** — 右上の 🌐 で表示言語を切替。設定は次回も引き継がれる
- **🎹 音色セット** — 「ピコピコ 8bit」「まろやか 16bit」「きらめき 32bit」の 3 種類。
  切り替えると画面の配色も一緒に衣替えする
- **🎼 65 種類の曲調** — メジャー / マイナー / 各種教会旋法・旋律的短音階・和声的短音階の旋法 /
  和風・琉球・都節などの日本音階 / ブルース・ジャズ・全音・ディミニッシュ / ペルシャ・アラビア・
  ハンガリーなど世界の音階（＋写真から作る「フォト音階」）
- **✨ 自動作成** — ワンボタンで作曲。「シード値」を控えておけば同じ曲をいつでも再現。
  コード進行（各曲調に 500〜4,000 種類・全体で **約 12 万通り**）× **ベース 384 種** ×
  **伴奏 600 種** × **リズム 208 種** × メロディのリズム 10 種 × 展開 6 種
  （演奏スタイルだけで **28 億通り超**）をシード値で組み合わせ、毎回違う曲が生まれる。
  進行は機能和声（トニック / サブドミナント / ドミナント）に代理和音を含めて自動生成。
  作成後は使われたコード進行（例: Am→F→C→G）を画面下に表示
- **🥁 リズム 208 / ベース 384 / 伴奏 600 種** — 1 つずつ手書きするのではなく、
  音楽的に意味のある軸の組み合わせで組み立てている（コード進行と同じ考え方）。
  - リズム = **骨格 13**（ロック / 八分 / 三分割 / バックビート / ハーフタイム / 裏打ち /
    クラーベ / ボサノヴァ / アーメン / ギャロップ / トライバル / ドラムンベース / スタッター）
    × **密度 4 段**（抜き ⇄ 詰め）× **アクセント 4 種**
  - ベース = **動き 8**（ペダル / 根音5度 / 歩き / アルペジオ / オクターブ / 半音 / 駆上がり / 三度）
    × **刻み 3**（半小節 / 4分 / 8分）× **変化 8**（素直 / シンコペ / 付点 / グレース /
    2小節フレーズ / 追い込み / 先取り / 後半ずらし）× **音域 2**（低音を張る / 1オクターブ上で弾ませる）
  - 伴奏 = **取り方 5**（根音 / 3度 / 5度 / 上行・下行アルペジオ）× **置き方 4**（拍頭 / 裏 /
    8分 / パッド）× **変化 6**（素直 / シンコペ / 先取り / 2小節フレーズ / 追い込み / もたれ）
    × **長さ 5**（短く刺す ⇄ 長く敷く）
  - まばらな型から詰まった型まで密度に幅があり、抜き差しで曲の起伏が作れる
  - **数字の内訳**: 型の数と「刻みの形」の数は別物。音程や音の長さを変える軸
    （アクセント・動き・音域・取り方）を増やしても刻みは増えないので、
    リズムに効く軸を別に用意している。刻みの形は **リズム 52 / ベース 24 / 伴奏 22 通り**。
    伴奏は当初 100 型あったが刻みは置き方の 4 通りだけで、別シードでも 4 回に 1 回は
    同じ刻みだった（「変化」軸を足して 22 通りにし、一致率 25% → 4.6%）
- **🎵 メロディは「歌える」ように作る** — 型の数だけでなく歌としての質を作り込んでいる。
  同じ音を続けられる回数に上限を設け（同音の連打で止まらない）、どんなに疎なリズム型でも
  最低音数を保証（メロディの無いフレーズを作らない）、拍頭はコードトーンを守りつつ
  裏拍には**経過音**を通す（安全すぎない歌の輪郭）。
  さらに**ベースの動きを見て反行を取る** — 土台と同じ向き・同じ音名へ進むことを避けるので、
  2 声が 1 つに聞こえて薄くなる瞬間が起きにくい
- **🔊 音符ごとの強弱** — アクセントが音の長さだけでなく**音量**でも張られる。
  小節頭 ＞ 拍頭 ＞ 裏拍 ＞ 埋めの音（ゴーストノート）の 4 段で、フレーズに拍の階層が出る。
  フレーズ最後の半小節はリズムが一段強くなり、次のループへの煽りになる。
  強弱はピアノロールの明るさで見え、WAV にも MIDI のベロシティにも反映される
- **🎯 曲調に合った演奏が選ばれる** — 音階の音の並びから曲調の性格（明るい / 叙情 /
  エキゾチック / ブルース / 幻想 / 五音・民族 / 激しい など 11 グループ）を判定し、
  **リズム・ベース・伴奏・メロディの 4 パートすべて**で、その性格が得意な型を**出やすく**する。
  例: 和風→太鼓系＋間を活かした薄い伴奏、ボス戦→倍テン・DnB＋16分ベース、幻想→ボサ＋パッド。
  **禁止はしないのでどの型もどの曲調でも出る**（性格と意外性の両立）
- **🎲 サプライズ** — 曲調・**キー**・音色・**拍子**・**テンポ**・シード値に加え、各パートの**音色（パルス幅など）と
  長さ**まで、まるごとランダムに選んで一発生成。65 種類の曲調から、質感まで思いがけない組み合わせに出会える。
  - **どのキーでもメロディの音域は同じ幅**（2 オクターブ）。主音の位置だけで音域を決めると、
    高いキーほど上限に押し潰されて幅が半分になってしまうため、床に下限を設けている
  - **テンポは曲調に合った範囲から選ぶ** — 激しい曲調なら 150〜180、幻想なら 80〜105 など。
    演奏の型だけ曲調に寄せてもテンポが逆では台無しなので、11 の性格グループごとに範囲を持つ
  - **拍子も 2/4〜7/4 から抽選**（4/4 を厚めにした重み付き）。ソング構成を組み立て済みのときは
    拍子を振らない（ブロック長が変わると構成をリセットせざるを得ないため）
- **🎼 ソング自動作成** — イントロ→Aメロ→Bメロ→アウトロの 1 曲構成を丸ごと生成
  （各パターンに Intro / A / B / Outro の既定名が付く）。
  **曲の設計図もシード値で選ばれる** — 並び 6 種（王道 / AABA / 交互 / B主体 /
  長いイントロ / 畳みかけ）× イントロの厚み 3 種 × アウトロの余韻 3 種 = **54 通りの構成**。
  A メロと B メロは別シード・別コード進行なので必ず対比になる
- **🎧 DJ モード** — 大きなターンテーブル 2 枚を回すリアルタイム演奏画面。**8 小節ごとに次のフレーズを
  自動生成して継ぎ目なく流し続け**（裏で先に用意しダウンビートで差替え）、**ディスクをドラッグで
  スクラッチ**。クロスフェーダーでデッキ切替、**ノイズ / フィルター / KILL** で盛り上げ、**🔁 ループ固定**で
  現フレーズを保持
- **🗂 パターン編集タブ** — フレーズとソングの間の専用タブ。保存したパターン（最大 8）を
  一覧で管理: 盤面へ読込（編集）・名称変更・複製・削除・試聴
- **🎸 伴奏づけ** — メロディを描くだけで、合うベース・リズム・伴奏を自動生成
- **📷 写真から** — 写真の中の四角形（最大 8 個）を「使える音」に変換し、
  曲調に「フォト音階」として追加。その音だけで作曲するインスピレーション機能
- **編集ツール** — オクターブ移調（🔼🔽 / Ctrl+↑↓）、フレーズの時間反転（🔄）、
  パート単位の消去（パートボタンを右クリック）
- **リアルタイム反映** — 演奏を止めずに音を足す・消す・テンポ変更ができる
- **🎧 WAV / 🎹 MIDI 書き出し** — 音声ファイルに加え、DAW や楽譜ソフトで開ける
  標準 MIDI ファイルとしても書き出せる（パートは MIDI チャンネルで分離）
- 音の合成は整数計算のみ。同じデータからはどのパソコンでも同じ音の WAV が出る
- Python 標準ライブラリだけで動作（追加インストール不要）
- ウィンドウの大きさ・位置・パネルの分割サイズ・拡大率・言語は次回起動時に復元される

任意で入れると良いもの: `numpy`（合成が速くなる）、`Pillow`（JPEG 写真の読み込み）。
どちらも無くても全機能が動きます（PNG / BMP / PPM は内蔵デコーダで対応）。

## 動かし方

Python 3.9 以上（Windows 想定）。

```console
py main.py            # アプリを起動
py main.py --demo     # デモ曲入りで起動
py main.py --selftest # 画面を出さずに動作を自己診断（終了コード 0 = 正常）
py -m unittest        # テストを全実行
py -m picoseq.vision 写真.jpg   # 写真の解析だけをコマンドラインで確認
```

音の再生は Windows 標準の機能を使います。ほかの OS では編集と WAV 書き出しはできますが、
その場での試聴は鳴りません。

### exe にする

配布用にビルドするには（初回のみ PyInstaller を自動インストール）:

```console
build_exe.bat
```

中身が同じ 2 種類ができます。Python の入っていないパソコンでも動きます。

| 成果物 | 起動時間（実測） | 向き |
| --- | --- | --- |
| `dist\PicoSeq\PicoSeq.exe`（フォルダ版） | **1.7〜1.9 秒** | 普段の配布（zip で渡す） |
| `dist\PicoSeq-portable.exe`（単一ファイル） | 5.1〜5.7 秒 | 1 ファイルで持ち運びたいとき |

単一ファイル版は起動のたびに中身を一時フォルダへ展開するため、その分だけ待ちます。
どちらも同じ機能・同じ音です。

### ブラウザで動かす（インストール不要）

<https://ksan260307.github.io/picoseq/> で試聴デモ、
<https://ksan260307.github.io/picoseq/app/> でブラウザ版アプリが動きます。

ブラウザ版は Pyodide（WebAssembly 上の CPython）で
**デスクトップ版と同じ `picoseq/core` をそのまま**動かします。
エンジンを 2 つ持たないので、同じ曲調・キー・シード値なら出る曲も同じです。
画面だけ HTML + Canvas で作り直しています（`web/`）。

| | 試聴デモ `/` | ブラウザ版 `/app/` | デスクトップ版 |
| --- | --- | --- | --- |
| 用意された曲を聴く | ○ | ○ | ○ |
| 自動作成・サプライズ | − | ○ | ○ |
| 音を置く・伸ばす・強さを変える | − | ○ | ○ |
| 移調・反転・伴奏付け | − | ○ | ○ |
| WAV 書き出し / JSON 保存・読み込み | − | ○ | ○ |
| ソング構成・DJ モード・写真から音階・MIDI 書き出し | − | − | ○ |
| 起動 | すぐ | 初回のみ十数秒（Python の読み込み） | すぐ |

公開物は手元でも作れます:

```console
py tools/build_site.py site       # 試聴デモ（曲を生成して WAV とピアノロールを書き出す）
py tools/build_web.py site/app    # ブラウザ版（core を zip に固めて web/ を配置）
py -m http.server -d site 8000    # http://localhost:8000/ で確認
```

`build_web.py` は core が `tkinter` / `ctypes` / `threading` などブラウザで
使えないモジュールを掴んでいないかを検査してから固めます。
掴んでいたらビルドが失敗するので、**壊れたページが公開されることはありません**。
zip はファイル順と日時を固定して書くため、中身が同じなら毎回同じバイト列になります。

公開は `.github/workflows/pages.yml`（`main` への push、または手動実行）が担当します。
全テストが通ったときだけ両方を組み立てて GitHub Pages へデプロイします。
リポジトリ側は Settings → Pages → Source を **GitHub Actions** にする初回設定が必要です。

### スマホ (Android) 向けビルド

デスクトップ版の画面 (tkinter) はスマホでは動かないため、同じ作曲エンジンを使う
**軽量なモバイル版** (`mobile/`) を用意しています。GitHub Actions の
`Android APK` ワークフロー（手動実行、または `v*` タグの push）が
`mobile/main.py` + `picoseq` パッケージを Buildozer で APK にし、
Artifacts からダウンロードできます。設定は `.github/workflows/android.yml` と
`mobile/buildozer.spec` にあります。

モバイル版の機能: 自動作成 / ソング自動作成 / 音色・曲調・シード値の変更 / ループ再生。
※ APK ビルドは CI 上でのみ検証しています。実機での動作確認はお使いの端末で行ってください。

`ci.yml` は push / PR ごとに全テストと画面自己診断を実行し、
タグ時には Windows exe も Artifacts に置きます。

## 使い方

**フレーズ作成タブ**

- マス目を左クリックで音を置く。**そのまま右へドラッグで音を伸ばす**
- 音符をクリック、または右クリックで消す
- 左端の鍵盤をクリックで試聴
- 「パート」ボタン（キー `1`〜`4`）で 4 つのパートを切り替え
- **レイヤー** — パートの下の「＋ 追加」で層を増やす（各パート最大 8 層）。番号で層を選び、
  2 層目以降は「✕ N を削除」で消せる。層ごとに音色・音を分けられる
- **消音** — 「消音」行の 🔊/🔇 でパートごと、レイヤーバーの 🔊/🔇 でレイヤーごとにミュート。
  一部レイヤーだけ消音中のパートは 🔉 表示。再生・WAV に反映される
- **拡大・縮小** — ピアノロール見出しの － / 100% / ＋、または盤面で Ctrl＋マウスホイール
- **パネル** — 「操作」と「ピアノロール」の境界をドラッグして高さを調整。各パネルの「⧉ 切り離し」で
  独立ウィンドウに、「⧈ 戻す」で元へ
- 「質感」「長さ」「音量」スライダーでパート（層）ごとの音作り。**音量**で各パートの
  バランスを取れる（例: ベースを上げる、リズムを下げる）
- **✨ 自動作成** — 押すたびに新しい「シード値」で作曲。番号欄に入力して Enter で同じ曲を再現
- **🎸 伴奏づけ** — メロディに合わせて他 3 パートを自動生成
- **★ 登録** — 気に入ったフレーズをパターンとして保存（最大 8 個）

**📷 写真から（フォト音階）**

1. 「📷 写真から」で写真を選ぶ（本・カード・窓など、四角い物がはっきり写ったもの）
2. 見つかった四角形（最大 8 個）が番号と音名つきで表示される
3. 「♪ この音階で自動作成」または「🎼 音階だけ取り込む」を選ぶ

写真の変換ルール（同じ写真からは必ず同じ結果になります）:

| 写真の特徴 | 音楽への変換 |
| --- | --- |
| 各四角形の**横位置** | その四角形の音（左 = 低い、右 = 高い） |
| **いちばん大きい四角形** | 曲のキー（基準の音） |
| 全部の四角形の音 | 「フォト音階」＝この曲で使える音のセット |
| 四角形の**面積の合計** | テンポ（大きく写すほど速い） |
| 四角形の**位置の細部** | シード値（同じ写真 → 同じ曲） |

取り込んだ音階は曲調セレクタに「📷 フォト音階」として残り、いつでも選び直せます。

**パターン編集タブ**

- 保存したパターン（最大 8）を一覧で管理する専用画面（フレーズとソングの間）
- 各パターンで **✏ 編集**（盤面へ読込）・**🏷 名称変更**・**⧉ 複製**・**🗑 削除**・**▶ 試聴** ができる
- 空きスロットには「＋ ここへ保存」で現在のフレーズを保存
- 付けた名前はソング画面のマス目にも表示される

**ソング作成タブ**

- **「✨ ソング自動作成」** — パターン 1〜4（Intro / A / B / Outro）と
  16 ブロックの構成を丸ごと自動生成。そのまま ▶ で 1 曲聴ける
- パレットでパターンを選ぶと「配置中: 名前」が表示され、4 トラック × 16 ブロックのマス目に配置
- **▶ 試聴** — 選んだパターンをその場で 1 回鳴らして確認できる
- マス目には**パターン名**（無ければ F 番号）と上端に**ブロック番号**が出て、
  配置中パターンと同じマスは**明るい枠**で強調される。長い名前はマス幅に合わせて「…」で省略
- マス目にマウスを載せると、そこにあるパターンの正式名がステータスに出る
- 横に並べると連結、縦に並べると同時に鳴る
- 「🎵 WAV書出」で曲全体を音声ファイルに

**🎧 DJ モード**

- 大きなターンテーブル 2 枚（デッキ A / B）を回しながらリアルタイムに演奏する画面
- **▶ 回す** で開始すると、**8 小節ごとに次のフレーズを自動生成して継ぎ目なく切り替わり続ける**
  （次ループを裏で先に用意し、**再生を止めずにサンプル単位で乗り換える**ので無音が一切入らない）
- スクラッチや試聴は**音楽に重ねて**鳴るので、演奏が途切れない
- **ディスクをドラッグ（マウス）するとスクラッチ**（ドゥビドゥビ）。音楽に重ねて鳴る。
  ディスクを動かさずにクリック（タップ）すると、そのデッキで新しいフレーズを生成
- **クロスフェーダー** でデッキ A ⇄ B を切り替え（別設定のデッキを仕込んでおいて展開）
- **曲調 / キー / テンポ / ノイズ / フィルター / ループ固定 / KILL は デッキごとに独立**した
  チャンネルストリップで設定する。片方を鳴らしながら、もう片方を仕込んでおける
  - **曲調**: 65 種類から**セレクタで任意に選択**（🎲 生成 はおまかせ）。
    両デッキとも初期値は「明るい（メジャー）」
  - **キー**: 12 キーから任意に選択。デッキごとに変えて転調、揃えて自然につなぐ、
    どちらもできる（曲調・キーの変更ではフレーズの骨格は保たれ、🎲 生成 のみが作り直す）
  - **音色**: フレーズ画面と同じ 3 種をデッキごとに。DJ 中は**画面の配色を変えない**ので
    ディスクが飛ばず、A と B に別の音色を仕込める
  - **ノイズ** (0〜4): ハイハット風の刻みと盛り上げロール
  - **質感 / 長さ / 音量（パートごと）**: 「パート」で メロディ / ベース / リズム / サブ を選び、
    そのパートの **質感**（メロディはパルス波のデューティ比 12.5%〜50%。細い電子音 ⇄ 太い矩形波）・
    **長さ**（ゲート。短いほど歯切れよく、長いほど伸びる）・**音量**（ミックスのバランス）を調整。
    音符は変えず音作りだけが変わる
  - **フィルター**: こもらせる ⇄ 開く（ローパス掃引）
  - **ループ固定**: 自動で進まず、そのデッキのフレーズをループし続ける。
    つまみを触ってもフレーズは変わらない（音作りだけが変わる）
  - **KILL**: 各パート（メロディ / ベース / リズム / サブ）をワンタッチ消音
  - **SYNC**: もう一方のデッキへ**テンポとキーを合わせる**。曲調・音色はそのままなので
    「別の曲調のまま拍とキーだけ揃えて重ねる」ことができる
- つまみの変更は**その場で音に反映**される（ループの継ぎ目を待たない）。**タップ**でテンポ合わせ
- 中央に**「次のフレーズまで N 小節」**が出るので、自動進行のタイミングが目で分かる。
  ループ固定中は**「🔁 このフレーズを固定中」**表示に変わる
- **🕘 履歴**: 流したフレーズが新しい順に並ぶ。行から **→A / →B で任意のデッキへ呼び戻し**、
  **★ でお気に入り登録**、**💾 でパターンとして保存**できる。
  **つまみを調整した状態も履歴に残る**ので（操作が落ち着いたところで 1 行として確定）、
  「さっき音を作り込む前の状態」へいつでも戻せる。溜まったら **クリア** で掃除
- **⏺ 録音**: 中央の録音ボタンで、鳴っているミックス（乗り換え・スクラッチ・ノイズ込み）を
  **そのまま WAV に書き出し**。もう一度押すと停止して保存先を選べる。聞こえた通りの 1 本になる
- **★ お気に入り**: 気に入ったフレーズは★で登録。**設定ファイルに残るので次回起動でも使える**。
  中央の **★ 登録 / 💾 残す** は、今鳴っている音をそのまま登録・保存するショートカット
- 記録しているのは音そのものではなく**フレーズを決める種**（曲調・キー・テンポ・音色・
  ノイズ・シード）だけ。決定論的に作り直せるので、何時間演奏しても記録は軽いまま

**再生と音色**

- `Space` で再生 / 停止。ループ再生
- **演奏中の編集はそのまま演奏に反映**（止める必要なし）
- テンポも演奏中に変えられる
- ヘッダーの「音色」で全体の音の性格を切替。**画面の配色も音色に合わせて変わる**
  （深緑 → 深紫 → 藍色）。音色は保存データに記録される

**キーボード**

| キー | はたらき |
| --- | --- |
| `Space` / `Esc` | 再生・停止 / 停止 |
| `1`〜`4` | パート切替 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+Tab` | フレーズ → パターン → ソング → DJ と切替 |
| `F1` | ヘルプ |

## しくみ（開発者向け）

ロジック（`picoseq/core/` — 純粋関数のみ）と画面（`picoseq/ui/`）を分けた構成。
乱数は必ず「シード値」から生成し、音の合成は整数計算だけで行うため、
**同じプロジェクトからはどの環境でも 1 ビットたがわず同じ WAV** が出ます。

### 設計のポイント

| 方針 | 内容 |
| --- | --- |
| 再現性 | 乱数は「シード値」からのみ。同じ設定 → 常に同じ曲・同じ WAV |
| 順序に依存しない | ミックスは整数の足し算。処理順を変えても結果は同一 |
| 環境に依存しない | 音の合成は整数演算のみ。numpy 経路も純 Python 経路と完全一致（テストで保証) |
| 表示と分離 | 再生位置の表示だけが実時間を使い、曲データには影響しない |
| 保存形式 | アプリ ID と形式バージョン付き JSON。将来版・別アプリのデータは安全に拒否 |
| 後方互換 | 旧形式 (v1/v2) のデータ、旧ブラウザ版の retro_project.json も読み込める |

### テスト

`py -m unittest` で全テストを実行。音の波形・PCM はチェックサムで固定してあり、
音を変えてしまう変更はテストが検知します。UI は `--selftest`（主要操作の一巡）で確認できます。
