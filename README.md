# PicoSeq — レトロピコピコ・シーケンサー

ファミコン風のピコピコ音楽を作って鳴らすデスクトップアプリ。
マス目に音を置くだけで演奏でき、写真や鼻歌からも曲を作れます。

**English version: [README.en.md](README.en.md)**

## 特長

- マス目に音を置いてフレーズを作り、フレーズを並べて 1 曲に組み立てる
- 4 パート（メロディ / ベース / リズム / サブ）を重ねられる
- **🎹 音色セット** — 「ピコピコ 8bit」「まろやか 16bit」「きらめき 32bit」の 3 種類。
  切り替えると画面の配色も一緒に衣替えする
- **✨ 自動作成** — ワンボタンで作曲。「シード値」を控えておけば同じ曲をいつでも再現。
  ベース 6 種 × 伴奏 5 種 × リズム 6 種 × メロディのリズム 4 種 × 展開 3 種を
  シード値で組み合わせ、4000 通り超の土台から毎回違う曲が生まれる
- **🎼 ソング自動作成** — イントロ→Aメロ→Bメロ→アウトロの 1 曲構成を丸ごと生成
- **🎤 鼻歌から** — マイクに歌うと声の高さを読み取ってメロディに変換
  （倍音の多い声でもオクターブを取り違えにくい YIN 系の音高検出）
- **🎸 伴奏づけ** — メロディを描くだけで、合うベース・リズム・伴奏を自動生成
- **📷 写真から** — 写真の中の四角形（最大 8 個）を「使える音」に変換し、
  曲調に「フォト音階」として追加。その音だけで作曲するインスピレーション機能
- **リアルタイム反映** — 演奏を止めずに音を足す・消す・テンポ変更ができる
- 音の合成は整数計算のみ。同じデータからはどのパソコンでも同じ音の WAV が出る
- Python 標準ライブラリだけで動作（追加インストール不要）

任意で入れると良いもの: `numpy`（合成が速くなる）、`Pillow`（JPEG 写真の読み込み）。
どちらも無くても全機能が動きます（PNG / BMP / PPM は内蔵デコーダで対応）。

## 動かし方

Python 3.9 以上（Windows 想定）。

```console
py main.py            # アプリを起動
py main.py --demo     # デモ曲入りで起動
py main.py --selftest # 画面を出さずに動作を自己診断（終了コード 0 = 正常）
py -m unittest        # テストを全実行
py -m picoseq.vision 写真.jpg   # 写真の解析だけをコマンドラインで確認
```

音の再生は Windows 標準の機能を使います。ほかの OS では編集と WAV 書き出しはできますが、
その場での試聴は鳴りません。

### exe にする

配布用の単一 exe を作るには（初回のみ PyInstaller を自動インストール）:

```console
build_exe.bat
```

`dist\PicoSeq.exe` ができます。Python の入っていないパソコンでも動きます。

### スマホ (Android) 向けビルド

デスクトップ版の画面 (tkinter) はスマホでは動かないため、同じ作曲エンジンを使う
**軽量なモバイル版** (`mobile/`) を用意しています。GitHub Actions の
`Android APK` ワークフロー（手動実行、または `v*` タグの push）が
`mobile/main.py` + `picoseq` パッケージを Buildozer で APK にし、
Artifacts からダウンロードできます。設定は `.github/workflows/android.yml` と
`mobile/buildozer.spec` にあります。

モバイル版の機能: 自動作成 / ソング自動作成 / 音色・曲調・シード値の変更 / ループ再生。
※ APK ビルドは CI 上でのみ検証しています。実機での動作確認はお使いの端末で行ってください。

`ci.yml` は push / PR ごとに全テストと画面自己診断を実行し、
タグ時には Windows exe も Artifacts に置きます。

## 使い方

**フレーズ作成タブ**

- マス目を左クリックで音を置く。**そのまま右へドラッグで音を伸ばす**
- 音符をクリック、または右クリックで消す
- 左端の鍵盤をクリックで試聴
- 「パート」ボタン（キー `1`〜`4`）で 4 つの層を切り替え
- 「音色」「長さ」スライダーでパートごとの音作り
- **✨ 自動作成** — 押すたびに新しい「シード値」で作曲。番号欄に入力して Enter で同じ曲を再現
- **🎤 鼻歌から** — 録音（6 秒）または WAV ファイルからメロディを起こす
- **🎸 伴奏づけ** — メロディに合わせて他 3 パートを自動生成
- **★ 登録** — 気に入ったフレーズをパターンとして保存（最大 8 個）

**📷 写真から（フォト音階）**

1. 「📷 写真から」で写真を選ぶ（本・カード・窓など、四角い物がはっきり写ったもの）
2. 見つかった四角形（最大 8 個）が番号と音名つきで表示される
3. 「♪ この音階で自動作成」または「🎼 音階だけ取り込む」を選ぶ

写真の変換ルール（同じ写真からは必ず同じ結果になります）:

| 写真の特徴 | 音楽への変換 |
| --- | --- |
| 各四角形の**横位置** | その四角形の音（左 = 低い、右 = 高い） |
| **いちばん大きい四角形** | 曲のキー（基準の音） |
| 全部の四角形の音 | 「フォト音階」＝この曲で使える音のセット |
| 四角形の**面積の合計** | テンポ（大きく写すほど速い） |
| 四角形の**位置の細部** | シード値（同じ写真 → 同じ曲） |

取り込んだ音階は曲調セレクタに「📷 フォト音階」として残り、いつでも選び直せます。

**ソング作成タブ**

- **「✨ ソング自動作成」** — パターン 1〜4（イントロ / Aメロ / Bメロ / アウトロ）と
  16 ブロックの構成を丸ごと自動生成。そのまま ▶ で 1 曲聴ける
- パレットでパターンを選び、4 トラック × 16 ブロックのマス目に配置
- 横に並べると連結、縦に並べると同時に鳴る
- 「🎵 WAV書出」で曲全体を音声ファイルに

**再生と音色**

- `Space` で再生 / 停止。ループ再生
- **演奏中の編集はそのまま演奏に反映**（止める必要なし）
- テンポも演奏中に変えられる
- ヘッダーの「音色」で全体の音の性格を切替。**画面の配色も音色に合わせて変わる**
  （深緑 → 深紫 → 藍色）。音色は保存データに記録される

**キーボード**

| キー | はたらき |
| --- | --- |
| `Space` / `Esc` | 再生・停止 / 停止 |
| `1`〜`4` | パート切替 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+Tab` | フレーズ ⇄ ソング |
| `F1` | ヘルプ |

## しくみ（開発者向け）

ロジック（`picoseq/core/` — 純粋関数のみ）と画面（`picoseq/ui/`）を分けた構成。
乱数は必ず「シード値」から生成し、音の合成は整数計算だけで行うため、
**同じプロジェクトからはどの環境でも 1 ビットたがわず同じ WAV** が出ます。

```
picoseq/
├── main.py                起動スクリプト（--selftest / --demo）
├── build_exe.bat          exe 化スクリプト
├── picoseq/
│   ├── core/              ロジック（純粋関数のみ。I/O・描画・実時間なし)
│   │   ├── constants.py   上限値・パート定義
│   │   ├── prng.py        シード値から同じ乱数列を作る生成器
│   │   ├── music.py       キー / 音階 / コード / 周波数表（フォト音階対応)
│   │   ├── note.py        音符 1 個 = 32bit 整数のパック表現
│   │   ├── phrase.py      フレーズ（音符の集まり）の操作
│   │   ├── song.py        ソンググリッドの操作
│   │   ├── project.py     アプリ全体のデータ（不変オブジェクト)
│   │   ├── actions.py     すべての編集操作（純粋関数)
│   │   ├── composer.py    自動作曲・伴奏生成
│   │   ├── arranger.py    メロディからコード進行を推定して伴奏を付ける
│   │   ├── humming.py     鼻歌の音程検出（自己相関・整数演算)
│   │   ├── schedule.py    時刻計算・イベント展開
│   │   ├── synth.py       固定小数点シンセ（パルス/三角/ノイズ/ノコギリ)
│   │   ├── renderer.py    ミックス（音声キャッシュ・numpy 高速経路つき)
│   │   ├── wavio.py       WAV 形式の書き出し
│   │   ├── serialize.py   バージョン付き JSON 保存・旧版データの移行
│   │   └── history.py     元に戻す / やり直す
│   ├── vision/            フォト音階（画像解析)
│   │   ├── image.py       画像読み込み（PNG/BMP/PPM 内蔵デコーダ)
│   │   ├── quad.py        四角形検出（複数しきい値・最大 8 個・重複除去)
│   │   ├── harmony.py     四角形 → 音階への変換
│   │   └── __main__.py    コマンドライン確認用
│   └── ui/                画面（データは actions 経由でのみ変更)
│       ├── app.py         画面の組み立て・配線・リアルタイム再生
│       ├── roll_view.py   ピアノロール
│       ├── song_view.py   ソンググリッド
│       ├── photo.py       フォト音階ダイアログ
│       ├── hum.py         鼻歌ダイアログ
│       ├── mic.py         マイク録音（Windows 標準機能を直接利用)
│       ├── help.py        ヘルプ画面
│       ├── playback.py    再生・再生位置時計・途中からの再生
│       ├── storage.py     ファイル置き場
│       └── theme.py       配色・フォント
└── tests/                 テスト（py -m unittest で全実行)
```

### 設計のポイント

| 方針 | 内容 |
| --- | --- |
| 再現性 | 乱数は「シード値」からのみ。同じ設定 → 常に同じ曲・同じ WAV |
| 順序に依存しない | ミックスは整数の足し算。処理順を変えても結果は同一 |
| 環境に依存しない | 音の合成は整数演算のみ。numpy 経路も純 Python 経路と完全一致（テストで保証) |
| 表示と分離 | 再生位置の表示だけが実時間を使い、曲データには影響しない |
| 保存形式 | アプリ ID と形式バージョン付き JSON。将来版・別アプリのデータは安全に拒否 |
| 後方互換 | 旧形式 (v1/v2) のデータ、旧ブラウザ版の retro_project.json も読み込める |

### テスト

`py -m unittest` で全テストを実行。音の波形・PCM はチェックサムで固定してあり、
音を変えてしまう変更はテストが検知します。UI は `--selftest`（主要操作の一巡）で確認できます。
