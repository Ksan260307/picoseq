PicoSeq Web

デスクトップ版と同じ作曲エンジン (Python) を そのままブラウザで動かしています。作った曲はシード値で再現できます。

エンジンを読み込んでいます…

初回は Python 本体 (約 10MB) を取得します。2 回目以降はキャッシュされます。

パート

マス目をクリックで音を置く／もう一度で消す。右へドラッグで伸ばす。 Shift+クリックで音の強さを切り替え。

ブラウザ版で出来るのはフレーズ 1 つの作曲・編集・試聴です。 ソング構成・DJ モード・写真からの音階・レイヤーはデスクトップ版のみ。
